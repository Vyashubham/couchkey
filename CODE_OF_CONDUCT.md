# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work,
and don't harass anyone. Maintainers may remove comments, commits, or
contributors that break these rules.

## Reporting

Report unacceptable behavior privately to the maintainers through GitHub
(a private security advisory works for anything sensitive). Reports are
handled confidentially.
